## Правило после каждого этапа
1. `npm run typecheck`
2. `npm run lint`
3. `npm run test` (если есть тесты для этапа)
4. `npm run build`
5. Исправить ошибки → только потом переходить дальше.

нужно будет запустить тебе или Vercel.
