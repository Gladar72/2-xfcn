# МЕСТО iOS 0.5.3

Сборка 64 из клиентского коммита `117c97c` [загружена в App Store Connect](https://github.com/Gladar72/2-xfcn/actions/runs/45326823044). Apple присвоила ей статус VALID. В серверной ветке прошли 219 модульных тестов и SQL-проверка выдачи билетов и повторной обработки операций. Действительная покупка и доставка чека гостю в этих тестах не проверялись.
