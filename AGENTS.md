# Как работать с репозиторием «МЕСТО»

Начинай с ветки текущей задачи и одного раздела. Из соседних разделов открывай файлы по мере появления конкретной зависимости.

| Раздел | Что здесь искать |
| --- | --- |
| `web` | Экраны Telegram Mini App и сайта в `app/`, общие компоненты в `components/` |
| `mobile` | Приложение iOS и Android в `mobile/` |
| `server` | API в `app/api/`, бизнес-логика в `lib/`, база в `supabase/`, проверки в `tests/` |
| `bot` | Обработчики Telegram в `app/api/telegram/`, клиент и уведомления в `lib/telegram/`, сценарии в `n8n/` |
| `media` | Баннеры в `public/promo/`, графика в `public/`, `assets/` и `mobile/assets/` |
| `ops` | Сборки и релизы в `.github/`, сервер в `deploy/` |

## Найти нужный файл

В локальной копии запусти, например, `python3 scripts/repo-context.py bot --match webhook`. Команда показывает до 16 путей и короткие хеши объектов Git за раз. Для другой страницы добавь `--page 2`, для другой доступной ветки или коммита — `--ref ИМЯ`. По умолчанию команда смотрит в коммит HEAD. Для незакоммиченных изменений смотри `git status --short` по каталогам задачи.

При работе через GitHub запроси содержимое конкретного каталога на нужной ветке. Из ответа выведи только подходящие имена, размеры и SHA. Для текста открой нужный диапазон строк. Для PR начни со списка изменённых путей, для GitHub Actions — со статуса и нужного шага. Ограничивай вывод **до** передачи в обсуждение, особенно для длинных строк, diff и журналов.

Баннеры, видео и архивы передавай как файлы. В обсуждении достаточно пути или ссылки, размера и хеша. Старые скрипты `apply-*.sh` открывай по имени, когда задача касается истории конкретного изменения.

## Продолжить после обрыва

После проверяемого этапа обнови краткую запись в описании рабочего PR или в `docs/work/` для задачи без PR. Укажи ветку и коммит, что проверено, где виден результат и какой шаг следующий. При продолжении сначала сверь запись с актуальным состоянием ветки. Для операций с внешним эффектом, например отправки сообщения, проверь факт выполнения перед повтором.

Запись по [тестовой отправке анонса iPhone](docs/work/telegram-app-store.md).
